## 📖 نبذة عن المشروع (About the Project)

**YP Mouse Pro** هو نظام متكامل للتحكم عن بُعد بأجهزة الكمبيوتر واللابتوب عبر الهاتف الذكي، تم تصميمه بهندسة برمجية عالية الأداء تجمع بين:
- **تطبيق الجوال (Android APK):** مبني بتقنية Flutter مع واجهات زجاجية حديثة ودعم كامل لترددات الشاشة حتى 120Hz.
- **خادم الكمبيوتر (Windows Desktop Server):** برنامج مستقل بصيغة `.exe` يعمل مباشرة على أي لابتوب بنظام Windows دون الحاجة لتثبيت Python أو أي برامج أخرى.
- **بروتوكول البث اللحظي (Ultra-Low Latency UDP):** تم هندسة نقل حركة الماوس عبر حزم ثنائية (Binary UDP) بزمن استجابة أقل من 1 ملي ثانية لتجربة سلسة وناعمة تضاهي الماوس السلكي الحقيقي.

## ⚡ أبرز المميزات (Key Features)

### 1. 🎯 لوحة تتبع فائقة النعومة (Smart Trackpad)
* **استجابة لحظية 120 FPS:** تحريك الماوس بإصبع واحد بسلاسة تامة وانعدام التقطيع.
* **إيماءات اللمس المتعدد (Multi-Touch Gestures):**
  * نقرة بإصبع واحد = كليك يسار (Left Click).
  * نقرة بإصبعين = كليك يمين (Right Click).
  * تمرير بإصبعين = سكرول ناعم للأعلى والأسفل (Smooth Kinetic Scroll).
  * سحب وإفلات ذكي (Smart Drag & Drop).
  * زووم تكبير وتصغير (Pinch-to-Zoom).

### 2. 📡 اتصال تلقائي فوري وسهل (Zero Configuration)
* **البحث التلقائي في الشبكة (Auto Discovery):** يكتشف التطبيق خادم الكمبيوتر في شبكة الـ Wi-Fi بنقرة زر واحدة ويتصل به تلقائياً.
* **الاقتران الفوري عبر الباركود (QR Code):** امسح رمز الـ QR الظاهر على شاشة الكمبيوتر بكاميرا الهاتف للاتصال والاقتران في ثانية واحدة.
* **دعم كافة الشبكات والـ Hotspot:** يعمل بكفاءة سواء عبر راوتر منزلي أو نقطة اتصال الهاتف المحمول (Mobile Hotspot) أو كابل LAN.

### 3. ⌨️ لوحة مفاتيح متكاملة ودعم عربي كامل (Full Keyboard & Arabic Input)
* كتابة النصوص العربية والإنجليزية والرموز التعبيرية (Emojis) مباشرة إلى أي برنامج أو لعبة على الكمبيوتر.
* اختصارات الويندوز السريعة: نسخ (`Ctrl+C`)، لصق (`Ctrl+V`)، تراجع (`Ctrl+Z`)، حفظ (`Ctrl+S`)، التبديل بين النوافذ (`Alt+Tab`).

### 4. 🎮 يد تحكم ألعاب افتراضية (Virtual Gamepad Controller)
* واجهة تحكم مخصصة للألعاب بمفاتيح اتجاهات وأزرار إجراءات تناسب ألعاب الكمبيوتر المختلفة.

### 5. 🖥️ أدوات التحكم بالنظام والوسائط (System & Media Tools)
* التحكم في الصوت (رفع / خفض / كتم).
* التحكم في سطوع شاشة الكمبيوتر مباشرة من الجوال.
* إيقاف تشغيل الكمبيوتر، إعادة التشغيل، أو قفل الشاشة عن بُعد.
* مشاركة الحافظة (Clipboard Sync) بين الهاتف والكمبيوتر.

## 🚀 طريقة التشغيل والاستخدام (Step-by-Step Guide)

```
       [خطوة 1: الكمبيوتر]                           [خطوة 2: الهاتف]
  افتح YPMouseProServer.exe                   ثبت وافتح YPMousePro.apk
              │                                          │
              └───────────────┬──────────────────────────┘
                              │
                    [خطوة 3: الاتصال]
          تأكد أن الهاتف والكمبيوتر متصلان بنفس شبكة الـ Wi-Fi
          اضغط "بحث واتصال تلقائي" أو صوّر رمز الـ QR من شاشة الكمبيوتر
                              │
                    [خطوة 4: مبروك!]
               تحكم بالماوس والكيبورد بسلاسة تامة
```

1. **على الكمبيوتر / اللابتوب:**
   * شغّل ملف `YPMouseProServer.exe` (أو `تشغيل_السيرفر.bat`).
   * سيعمل السيرفر تلقائياً وتظهر شاشة تعرض عنوان الشبكة والـ QR Code.
2. **على الهاتف المحمول:**
   * قم بتثبيت ملف `YPMousePro.apk` وافتحه.
   * تأكد من اتصال الجوال بنفس شبكة الواي فاي أو نقطة اتصال اللابتوب (Hotspot).
   * اضغط على زر **"بحث واتصال تلقائي"** أو اضغط **"مسح QR Code"** ووجّه الكاميرا لشاشة الكمبيوتر.
   * سيتم الاتصال فوراً ويبدأ التحكم مباشرة!

## 🛠️ المواصفات التقنية (Technical Specifications)

* **تقنية تطبيق الهاتف:** Flutter 3.x (Dart) مع بنية Responsive عالية الكفاءة.
* **تقنية الخادم:** Python Standalone (PyInstaller Executable) مع Flask & Flask-SocketIO و Win32 Native User32 Engine.
* **بروتوكول التحكم السريع:** Native UDP Datagram Socket على المنفذ `5004` لحركات الماوس وسكرول اللمس.
* **بروتوكول التحكم والخدمات:** WebSocket / Socket.IO و REST API على المنفذ `5001`.
* **منفذ الاكتشاف التلقائي:** UDP Broadcast على المنفذ `5002`.

## 🌐 English Overview

**YP Mouse Pro** is an ultra-low latency remote trackpad, keyboard, and gamepad system connecting your Android smartphone to any Windows laptop or desktop PC.

### Highlights:
- **Zero-Latency Movement:** Binary UDP streaming (`< 1ms` latency) with native 120 FPS sub-pixel Windows hardware mouse events.
- **Standalone Portable Server:** No Python, no dependencies, no installation required. Simply run `YPMouseProServer.exe` on any Windows machine.
- **Instant Pairing:** One-tap Auto-Discovery across Wi-Fi/Hotspot or instant QR code scanning.
- **Multitouch Gestures:** 1-finger click, 2-finger right click, 2-finger kinetic scroll, drag & drop, and pinch zoom.
- **Full Media & System Controls:** Volume, brightness, shortcuts, and full Unicode Arabic/English text typing.
